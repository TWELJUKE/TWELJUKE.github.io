データ削除のご案内

ちょいゲーで取得したデータの削除方法をご案内します。アプリ内から削除する方法と、アプリを開けない場合のメールでの申請方法があります。

最終更新: 2026年11月16日

1. アプリ内から削除する（推奨）

  1. ちょいゲーを起動します。
  2. 画面下の「設定」タブを開きます。
  3. 「データ削除」をタップします。
  4. 確認画面の「削除する」をタップします。

削除はすぐに実行されます。削除後は、コイン、宝石、ランキング、表示名などのデータを復元できません。

2. アプリを開けない場合（メール申請）

メール: rkkdm62@gmail.com

件名: 「データ削除希望」
本文: プレイヤー名またはプレイヤーID、削除を希望する旨

本人確認のうえ、7日以内に受付をご連絡し、30日以内に削除します。プレイヤーIDが分からない場合も、表示名とアプリの利用状況をお知らせください。

3. 削除されるデータ

  • プレイヤーID、表示名、紹介コード
  • ゲームのスコア、プレイ履歴、ランキング、デイリータスクの達成状況
  • コイン残高、コインの獲得・利用履歴、購入した宝石の情報
  • 友だち紹介の関係、通報履歴
  • 登録した銀行口座情報、出金申請の履歴（登録・申請した場合）
  • 端末内に保存された設定情報（アプリの削除またはデータ削除で消去）

4. 削除後に保存されるデータ

不正利用の防止および法令対応のため、削除後もサーバーのバックアップを最大30日間保存する場合があります。保存期間の経過後、順次削除します。法令上保存が必要な情報がある場合は、必要な期間のみ保存します。

広告配信に伴う端末識別子等はGoogle AdMobが取得し、Googleのプライバシーポリシーに従って管理されます。当社が広告IDを単独で保存することはありません。
